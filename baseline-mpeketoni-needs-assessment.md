## Purpose of This Document

This baseline serves three functions:

1. **Receive and map** the group's existing local terminology into the shared framework before any training or lesson content is introduced
2. **Identify gaps** — ecological domains where local knowledge is strong, thin, or absent — so that lesson content can be prioritised toward real need rather than assumed gaps
3. **Establish a benchmark** against which progress can be measured after one season, two seasons, and one year of active participation

It is not a test. There are no wrong answers. The baseline is the starting point; the group defines it by describing what they already know.

## Section 2 — Knowledge Domain Inventory

For each ecological domain below, the baseline assessment asks three things:

- **Coverage** — how many named entities (species, habitats, processes) does the group have local terms for?
- **Depth** — for the entities they name, how much do they know about ecological role, seasonal behaviour, and relationship to other species?
- **Practical capacity** — can the group take productive action in this domain (plant, remove, monitor, restore)?

### 2A. Scoring rubric

Use this rubric when reviewing the local terms document and when conducting the baseline interview.

**Coverage score (per domain)**
| Score | Meaning |
|---|---|
| 0 | No local terms; domain not part of group's daily experience |
| 1 | 1–3 entities named; awareness level only |
| 2 | 4–10 entities named; working familiarity with the domain |
| 3 | 10+ entities named; domain is actively part of group knowledge |

**Depth score (per named entity)**
| Score | Meaning |
|---|---|
| 0 | Name only — no knowledge of role or behaviour |
| 1 | Name + one fact (e.g. "it is a tree that grows near water") |
| 2 | Name + ecological role + at least one relationship to another species or process |
| 3 | Name + role + seasonal/phenological knowledge + traditional use or management practice |

**Practical capacity score (per domain)**
| Score | Meaning |
|---|---|
| 0 | No prior action taken in this domain |
| 1 | Group has observed and documented but not intervened |
| 2 | Group has taken action but without a monitoring record |
| 3 | Group has taken action with before/after documentation or follow-up |

## Notes for the Reviewer

When the local terms document arrives, the intake process should:

1. Enter all terms into Section 3 without editing or correcting — the exact form matters
2. Score each term for depth using the rubric in Section 2A
3. Assign each term to a domain from Section 2B
4. Calculate domain coverage scores from the counts
5. Complete Sections 4 and 5 based on what the document reveals and any direct conversation with the group
6. Produce the Section 7 summary card

Terms that do not match any Swahili or scientific equivalent in existing reference materials should be flagged immediately for follow-up with a botanical or zoological advisor. These unexplained terms are the most likely candidates for undocumented local ecological knowledge.
